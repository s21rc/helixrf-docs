# Release notes

The latest firmware is always available from **My account → Downloads** on
[helixrf.com](https://helixrf.com/my-account/downloads/). Install it from the
web interface as described in
[Update the firmware](../getting-started.md#5-update-the-firmware).

## Latest

First release.

- Main screen with frequency, mode, filter, split and tuner status, S / Po, SWR,
  ALC, Vd and Id meters, and the radio's spectrum scope with waterfall.
- Three meter faces: Bars, Analog and Vintage.
- Touch control: band, mode, filter and frequency panels, tap-to-tune on the
  scope, preamp, attenuator, AGC, noise blanker and noise reduction.
- FT8, FT4, CW and RTTY decoding from the radio's USB audio, with DXCC country
  names for FT8 and FT4. CW has two decoders: NEURAL and CLASSIC.
- Web interface: live mirror of the main screen with tap-to-tune, settings,
  licence and firmware update over WiFi.
- Network radio server for wfview and similar LAN-radio software, with remote
  transmit off by default.
- Licence activation by Device ID, and a 14-day trial.
